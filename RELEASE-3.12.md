# Umbrale Companion 3.12

Improves partial-log EXP during a HUD outage when a new base reward and its party bonus arrive separately. A newly appended bonus after the pending base is distinguished from an old bonus already covered by the EXP bar. Old refinements and inserted old bonus rows keep their existing exclusion behavior.

Uses ordered visible notice evidence; it does not establish exact per-kill identity. Arbitrary message reordering or unread notices can still leave totals incomplete. Validation uses local images, native UI fixtures and synthetic timing scenarios, not live gameplay.

Close the companion before installing software files. Preserve state.json and caches.
