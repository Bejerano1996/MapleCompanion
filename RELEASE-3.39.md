# Umbrale Companion 3.39

Adds explicit, searchable reference-catalog connections to CCPLZ and MapleStory Classic. Open Settings → Additional quest sources → Refresh. Each row names its source, required level and listed EXP, and opens the exact quest page. Missing EXP stays unknown; records from different providers remain separate.

Only the two public quest indexes are fetched on user request, with serial ten-second spacing, a daily local cache and no retries after 403/429. A failed or malformed update preserves the saved catalog. No source pages, cached catalogs, character saves or private screenshots are bundled. MapleStory Classic's structured game data is attributed to MapleClassic Wiki under CC BY-NC-SA 4.0; original guides are not reproduced.

This is reference discovery, not complete replacement of the NiaDB data engine. Provider names and slug URLs do not establish game quest IDs, objectives or portal routes. Therefore tracked quest state, GPS and measured EXP are not overwritten. Existing NiaDB access remains paused pending actual renewed operator approval. Sending an access-request email requires a connected mail account; no renewal is claimed.

Public-page parser validation read 441 CCPLZ and 407 MapleStory Classic rows on 2026-11-19. These counts can change. This is website/catalog validation, not live-game testing.
