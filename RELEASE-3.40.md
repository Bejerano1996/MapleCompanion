# Umbrale Companion 3.40

Saved public quest catalogs now participate in local screen reading. Exact unknown titles produce separate source-attributed reference cards after two fresh AUTO observations; old cards expire. CCPLZ and MapleStory Classic can disagree on listed EXP, so values remain separate. Full chain / step aliases do not duplicate a shared source record, and a bare step counter is not treated as a quest title. No game IDs, objectives, prerequisites or routes are invented from catalog names.

Open Settings → Additional quest sources or Ctrl+Shift+F while the Companion has focus. The window loads its saved catalog, supports independent search words and an optional nearby-level filter, reuses rows, fits the monitor and stays a singleton. Explicit Refresh fetches only the public indexes with serial ten-second spacing, fixed-origin redirects and stop-on-refusal behavior. A failed main refresh keeps cached game data usable. Without a primary cache, the source button and limited reference mode remain available while the saved journal is preserved.

Core game-index refreshes now use validated disk snapshots: mandatory indexes, names, IDs and numeric fields must pass before an atomic pointer switches generations. Payload hashes are checked on reopening; a damaged latest snapshot can fall back to the complete preceding one. Invalid server output or a failed disk commit preserves both the prior in-memory model and restart data. Force refresh is confined to its loader thread. Existing legacy cache files remain intact.

Screen callbacks reject delayed evidence after journal edits, reset, AUTO changes and character/session changes. A focused crop cannot prove a quest was completed; retirement requires a full scan. The AUTO indicator reports actual evidence age. OS window metadata distinguishes the game from browser/document titles, and higher-window pixels are masked before OCR. Covered HUD/log/context regions are unavailable rather than misread; no game found means no desktop OCR. Native window closing saves pending changes.

Malformed optional shop pages and invalid prices retain their last saved records and raw page, including after restarting. Interrupted or malformed guide updates retain the previous guide-page group. Valid core updates can still complete while an optional update is rejected. Provider catalog mappings are published without mutating searches already in progress.

Repeated title matching was measured against the existing 401-quest local dataset: median matching time for 22 repeated lines fell from 48.627 ms to 0.122 ms after warm-up. The first uncached match still costs roughly the original time. 2,005 differential cases retained the same main quest matches. This is a matching-only benchmark, not a full OCR or live-game latency measurement.

Validation uses local cached public payloads, supplied recorded images, deterministic clock/window mocks, temporary character fixtures and a hidden UI lifecycle soak. It does not constitute live-game verification. No newly captured private desktop images, character saves or provider caches are bundled. MeowDB/NiaDB requests remain paused pending actual renewed operator approval; no approval or email delivery is claimed. Existing measured EXP, party accounting and kills-to-level behavior are covered by focused regressions.

Recorded OCR: 66 checks passed; cached-data logic: 141 passed; compact UI: 62 passed. The hidden lifecycle exercise completed 3,600 seconds and 214 cycles without callback errors or accumulated resource growth. It disables screen capture, hotkeys and background loading; it is not a visual-layout or live-game test. All 15 cache-free CI pattern groups also passed from an isolated source copy without provider data.
