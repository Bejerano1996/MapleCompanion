# Umbrale Companion 3.16

Prevents ghost mesos when stationary pre-session rows contain alternating repeated values and only some amounts are readable. If every concrete amount still fits its original position, partial OCR changes no longer prove that the notice stack moved.

Actual scroll remains supported when stationary values conflict and independent surviving rewards support movement. Truly indistinguishable periodic scroll can still be missed; the tool prefers incomplete counts to invented pickups.

Validated using supplied images, synthetic notice/party scenarios and isolated native UI, not live gameplay. Includes prior EXP calibration, context and parser fixes.

Close the companion before installing software files. Preserve state.json and caches.
