# Umbrale Companion workspace export

This repository contains the Umbrale Companion 3.29 source, test fixtures, and the training audit evidence collected during development. The Windows portable package is a separate release asset. Extract the ZIP on Windows and run Umbrale Companion.exe. The package does not carry local session state.

The archive inventory records the names, sizes and SHA-256 hashes of the historical ZIPs available on the originating machine. An inventory entry alone does not indicate that the ZIP has been uploaded.

See README.md for project usage, TRAINING.md for training behavior, and evidence/training-loop-handoff.md for verification history. The release was validated with local fixtures and simulations.
