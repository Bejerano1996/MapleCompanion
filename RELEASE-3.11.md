# Umbrale Companion 3.11

Explicit HUD levels outside the supported level1-99 EXP table are rejected. They no longer fall back to a different level inferred from EXP and percentage.

Abnormal multi-level or lower-level changes require a second matching-level observation within15seconds. Old pending observations expire; ordinary single-level gains and same-level net EXP losses retain their existing behavior.

Includes prior money confidence, partial notice identity, bounded retries and compact strip fixes. Validation uses local images, synthetic accounting and isolated native UI tests, not live gameplay. Unread notices can still leave pickup totals incomplete.

Close the companion before installing program files. Preserve state.json and caches.
