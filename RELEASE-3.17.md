# Umbrale Companion 3.17

Retains credited notice rows while partial coverage hides them, preventing old mesos messages from being credited again when uncovered. Hidden-row memory is bounded, follows supported scroll motion, and is replaced after a full observation or cleared when reading continuity resets.

Visible new pickups still use normal confirmation. Unique-pickup simulations found no duplicates in the tested moving-mask cases, but heavy masking still misses unseen or unconfirmed pickups; this is not complete telemetry.

Validated with local images, synthetic notice/party scenarios and native UI tests, not live gameplay.

Close the companion before installing software files. Preserve state.json and caches.
